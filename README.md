# How Many Tabs Do You Have Open?

![Competition](https://make.fun/badge/u-danu-how-many-tabs-do-you-have-open-d86e783d.svg)
![Rank](https://make.fun/badge/veneraxyz/u-danu-how-many-tabs-do-you-have-open-d86e783d-entry-v1/rank.svg)
![Reward](https://make.fun/badge/veneraxyz/u-danu-how-many-tabs-do-you-have-open-d86e783d-entry-v1/reward.svg)

One number: how many browser tabs are open right now.

The program writes exactly one number (digits only, plus a trailing newline) to `entry.txt` — an honest count of open browser tabs. No words, no punctuation, no second number.

## Run

```sh
MAKEFUN_OUTPUT_DIR=/output npx tsx main.ts
```
